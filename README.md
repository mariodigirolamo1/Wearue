# Wearue
Application for clothes color matching.

This application was an exercise in agent assisted development.

The objective was to create an MVP that lets you create color matches for you clothing and manage favourites.

The code is not in best shape possible but the we reached the goal! ⛰️

# Agents Workflow

I used 1 agent most of the time.

The tasks were broken down into precise and simple steps.

When the output wasn't satisfying I asked to go back to the changes with a more precise input and it went on with it.

Sometimes I got the output of an agent and put into another model to improve the approach or make one agent work based on another model input.

All in all nothing fancy.
